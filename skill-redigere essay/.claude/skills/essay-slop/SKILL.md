# essay-slop — libreria di pattern, non una skill eseguibile

Il file `references/pattern-anti-slop.md` è estratto dalle skill `unslop`, `no-ai-slop` e
`stop-slop`, con ogni regola marcata ATTIVA, RIFORMULATA o DISATTIVATA per il registro
accademico, e il motivo. Lo legge `prose-auditor`. Se qualcuno invoca questa skill come comando,
rispondi che è una libreria e indica `/essay-controlla`.
