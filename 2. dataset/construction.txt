                   RQ1 two-group dataset: how it is built
           Construction of rq1_two_group_dataset_v2.dta (28,478 startups, 57 variables)
                                       14 November 2026

This dataset keeps every course startup with a first VC round and splits it into two groups:
startups with a second VC round (R = 1) and startups with only one round (R = 0). It replaces
the round-2-only sample of rq1_core_dataset.dta, which conditions on reaching round 2. The
script, rq1_two_group_dataset_v2.py, is a copy of the core script with the changes described here.
Version 2 follows the feedback of the 13 November pitch: startups with an undisclosed round-1
amount are dropped instead of imputed, the HQ state Unknown stays a category, the fixed
outcome windows start at round 2 (round 1 for one-round startups), and 4- and 6-year windows
are added next to the 5-year one for a sensitivity check. Section 1 lists the inputs, Section 2 goes
through the script step by step, Section 3 shows how the variables enter the regressions, Section 4
lists what to keep in mind and Section 5 lists every variable. Each variable is tagged Main if the
main specification uses it (12 variables), Robustness if only checks and extensions use it (24), or
Not used if it only builds other variables or describes the sample (21).

2 Construction, step by step
Step 1. Load
The course file gives one row per startup (57,751 startups, all in the US, founded 2012 to 2019).
Blank sector and state are set to missing. 52,277 startups have at least one completed deal with a
valid date.

Step 2. Rounds, the two groups and the gap
Deals of one company on the same day are merged into one round, as in the core dataset. The
change is the join with round 2: it is now a left join, so every startup with a first VC round stays
in (34,822 startups), whether or not it ever raised a second one.
       roundk = k-th distinct date with a VC deal;
       sizek = Σ DealSize on that date;
       prek, postk = max valuation on that date
A round 2 dated after DATA_END is outside the observed period and is treated as no round 2
(828 startups). The group variable is


                                                      1
      two_rounds = R = 1[t2 exists and t2 ≤ 30 June 2022]
The gap exists only for R = 1. It enters the regression multiplied by R, so one-round startups stay
in the sample and the gap slope is estimated among two-round startups only:
      gap_months = (t2 − t1) / 30.44;
      log_gap = ln(1 + gap_months);
      log_gap_r2 = R · log_gap (0 if R = 0)
One startup with a gap above 10 years is dropped as a data error. Rounds are merged by date, so
a gap of 0 days cannot occur.

Step 3. Outcomes
Exit is an IPO or an acquisition, whichever comes first; failure uses the failure date of the course
file. An exit or failure dated before round 1 is a data error (58 startups dropped, leaving 34,763).
An exit or failure before round 2 is legitimate: a startup can be acquired, or close, without raising
a second round. The fixed windows start at round 2 for two-round startups, as in the pitch, and at
round 1 for one-round startups, which have no round 2:
      window_start = w0 = t2 if R = 1, t1 if R = 0
      exit = 1[exit date exists] (no window, no drops);
      exit_wy = 1[w0 ≤ exit ≤ w0 + w years];
      failure_wy = 1[w0 ≤ failure ≤ w0 + w years];
      full_window_wy = 1[w0 + w years ≤ 30 June 2022], w = 4, 5, 6
exit is the main outcome. It uses every exit recorded in the data, including the July to December
2022 exits after DATA_END. An exit or failure between round 1 and round 2 of a two-round
startup is outside its window and counts as 0 in exit_wy and failure_wy (26 startups whose first
recorded event comes before round 2, a likely dating error). For the 5-year window the variables
keep their v1 names (exit_5y, failure_5y, full_window). full_window marks the 9,263 startups
whose 5 years are fully observed (12,184 for 4 years, 6,769 for 6). These are flags, not filters: no
startup is dropped for an incomplete window. The survival clock below still starts at round 1.
      months_to_outcome = (min(exit, failure, DATA_END) − t1) / 30.44;
      outcome_is_exit, outcome_is_failure = which event stopped the clock (exit wins a tie);
      missing when t1 is after 30 June 2022 (661 startups)

Step 4. Controls, missing data, round-2 variables and keys
Controls are measured at round 1, as in the core dataset. Missing values are handled as asked at
the pitch:
      state = \Unknown" if HQ state is blank (19 startups), so i.state_id has an Unknown
      category;
      log_round1_size = ln(1 + size1): the 6,285 startups with an undisclosed round-1 amount are
      dropped (v1 imputed them by hot-deck; a random draw assumes the amount is missing at
      random).
      startup_age_at_round1 = year(t1) − year_founded;
      round1_number = #{completed non-exit deals with date ≤ t1}
Lead     investor   (lead_type,    lead_investor_age),   round-2    variables    (log_round2_size,
valuation_step_up, up_round, and delta_v = post-money r2 / post-money r1) and round-3
variables (Step 4b) follow the core rules. Round-2 and round-3 variables are missing for R = 0.

Step 5. Sector hype
The hype measures are built exactly as in the core dataset (sector share of VC money, z-scored
within sector), but they are attached by the sector and year (or quarter) of round 1, because
one-round startups have no round-2 year.
          shares,t = VC$s,t / Σs' VC$s',t;
          heats,t = (shares,t − means) / SDs, 2012 to 2022

and .csv, one row per startup sorted by company_id.

3 How the variables enter the regressions
    The main specification is a logit on all startups:
       logit exit i.two_rounds##c.heat c.log_gap_r2##c.heat ///
           log_round1_size round1_number startup_age_at_round1 i.lead_cat ///
           i.round1_yq i.sector_id i.state_id, vce(cluster sector_year_id)

Pr(exit = 1) = Λ(α + ρ1R + β1R·log_gap + β2heat + ρ2R·heat + β3R·log_gap×heat + γ'X(t1) +
                                   δyq + μsector + πstate)
ρ1 compares two-round with one-round startups; β1 and β3 keep their meaning from the core
design (speed, and speed × hype, among two-round startups). Before the regression, set the two
negative startup ages to missing (replace            startup_age_at_round1         =    .   if
startup_age_at_round1 < 0) and create lead_cat with encode lead_type.

4 Points to keep in mind
Follow-up time. exit has no window, so a startup with round 1 in 2012 has had ten years to exit
and one with round 1 in 2021 about one. The year-quarter FE absorb the average difference
between cohorts. Recent cohorts have also had less time to raise round 2, so the one-round share
rises from about 41% for 2012 to 2019 to 54% (2020), 78% (2021) and 99% (2022), as Table 5
shows. The fixed-window model (exit_5y if full_window == 1) is the check.

Exits before round 2. A startup acquired before it could raise a second round is in the one-round
group by construction.
   Dropped round-1 amounts. Dropping undisclosed amounts keeps only startups that disclosed
round 1. If disclosure is related to quality or to the market, the sample is selected; the dropped
share by group and year can be compared in the descriptives.
   Windows from round 2. A two-round startup starts its window later than a one-round startup
with the same round-1 date, so it needs round 2 by 30 June 2017 to enter the 5-year sample.
Faster startups are therefore more likely to have a full window. The 4- and 6-year windows show
how much the results depend on this cut.
   Lead investor. When a round has several leads, the first in file order is kept.
DealInvestorRelation.csv and Investor.csv are needed to run the script.
